# Demo data

HireBuddy ships with demo jobs and a demo talent pool so the full flow runs on stage.

**Jobs.** The shop names are made up and the descriptions are written in our own words. The role, area, pay and shift pattern of each job are modelled on public part-time listings in the Klang Valley, which we read by opening the listing pages normally on 10 Oct 2026. We did not scrape them, and no listing text or company name was copied. MIXUE only appears when a user types it in a prompt.

**Students.** All students are fictional. Their emails use `example.com`, so no email to them is ever delivered.

**Takeaway for the pitch:** across the listings that showed an hourly rate, entry-level part-time pay in the Klang Valley ranged from RM9 to RM12 an hour, with retail ambassador roles at RM12–18. One real weekend cashier listing offered RM50–60 a day for weekend shifts. For an 8-hour shift that's below the RM65.38/day legal minimum (Minimum Wages Order 2024, P.U.(A) 376, 6-day week). That's exactly the case HireBuddy's wage check catches.
