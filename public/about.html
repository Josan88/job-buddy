How HireBuddy works

A cafe owner in Subang has no HR team. Hiring a weekend barista means writing an ad, posting it, reading a pile of messages, comparing schedules and booking interviews. That's hours of work. HireBuddy does all of it from one sentence and shows its working.

1. One prompt in

“Need a weekend barista in Subang, RM12/hr, start next week.” The owner gives no further guidance. Students use the same agent from the other side: “I'm Aisyah from Sunway, I make espresso, free weekends.”

2. It plans

The agent writes a plan first. Each step names the tool that completes it, so the checklist on screen updates on its own as the work happens.

3. It calls real tools

  • check_minimum_wage checks the pay against Malaysia's Minimum Wages Order 2024 (RM8.72/hour, RM1,700/month). If the pay is illegal, the agent refuses to publish.
  • publish_job creates a live public job page with an apply form, then fetches the page back to prove it is up.
  • find_candidates searches the student talent pool by distance (Haversine over Klang Valley areas) and includes anyone who applied on the page.
  • screen_candidates scores every candidate out of 100: must-have skills 35, nice-to-have 5, shift availability overlap 25, distance 15, experience 15, pay fit 5. Every skill point quotes the candidate's own words.
  • schedule_interviews books slots that fit both the owner's hours and the candidate's free time, with no clashes. Each slot gets a real .ics calendar invite.
  • send_email sends each invite with the calendar file attached. Email goes through Resend when it is configured. Demo addresses stay in the public outbox.
  • On the student side, register_student, search_jobs and apply_to_job handle the profile, the gig search and the applications. Applications appear on the business's job.

4. It checks its own work

  • verify_screening recomputes every score independently and confirms each evidence quote appears word for word in the profile. That rules out invented qualifications.
  • verify_hiring_outcome checks that the job page is live and the pay is legal. It confirms every interview sits inside the candidate's availability with no overlaps. It downloads each .ics file and compares its times with the booking, and confirms every email states the right time and link.
  • Tools reject bad input with specific problems, for example “Body must state the interview time exactly as …”. The agent fixes the problem and retries, and the timeline shows each fix.
  • The agent cannot finish until the final verification passes.

5. A result you can verify

The owner gets a live job link, a ranked shortlist with evidence, booked interviews with calendar files, sent emails, and a permanent run log showing every step.

Runs inside WorkBuddy

HireBuddy is also an MCP server at /mcp, and the repo includes a WorkBuddy Skill. From WorkBuddy, the owner types the same one prompt. WorkBuddy calls hirebuddy_run and gets back the verified result, the self-check list and links. The step-by-step tools are exposed too, so WorkBuddy's own model can run the plan itself. Every run, from either place, appears on this site's run log.

Brains

With an LLM key (any OpenAI-compatible API, including Tencent Hunyuan), the model does the planning and writing, and the deterministic tools and checks keep it honest. Without a key, a rule-based autopilot drives the same tools, so a demo never fails because of a network issue.
